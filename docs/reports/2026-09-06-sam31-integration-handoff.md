## 3. 需求与实现范围

目标是保留 LAS 兼容接口，在相同五个诊断视频上比较动作、遮挡与场景事实。
动作事件、遮挡事件和长时间场景事实分开表达，不强迫所有语义使用同一粒度。

SAM3.1 提供位置、可见性和跨帧身份等有界证据；语义模型负责判定遮挡、出画、
检测丢失或未知。**检测消失不是遮挡证据，任务完成不是语义有效，校验通过不是视觉正确。**

早期设计使用 Qwen3-VL-8B-Instruct；用户随后授权 Doubao 远程语义推理。
实验固定身份为 `doubao-seed-2-1-pro-260628`。保留冻结 Qwen 结果，分别测量
Doubao-only 和 Doubao＋SAM，避免把更换语义模型的收益误归因于 SAM。

已实现的主要组件：

| 组件 | 已完成能力与主要入口 |
| --- | --- |
| 调度与状态 | 阶段路由、持久化任务、租约/重试/发布约束、指标；`src/las_repro/workers.py`、`store.py`、`pipelines/embodied.py` |
| 时间线与 SAM | 原始帧 PTS、采样边界、固定源码与资源身份、独立 CV worker；`src/las_repro/cv/timeline.py`、`sam31.py`、`worker.py` |
| 证据与缓存 | 内容寻址、哈希校验、原子发布、来源校验、摘要与遮挡候选；`src/las_repro/cv/artifacts.py`、`summary.py` |
| 语义判定 | 遮挡候选约束、独立场景分支、严格输出校验与一次修复；`src/las_repro/pipelines/occlusion.py`、`scene_semantics.py`、`output_validation.py` |

## 5. 实验与验收现状

### 5.1 冻结参考与比较

五视频为 `full_0001`、`full_0002`、`full_0004`、`full_0021`、`full_0024`。

`full_0002` 的英文 LAS 输入是完整视频转码，而非原文件字节；其余四个使用相同
冻结视频字节。所有比较须保留此限制并指明参考版本。

### 5.2 缓存与恢复

全流程缓存复跑的第一个任务在两次无效 Pass B 响应后失败，后四个未提交。
Pass A 实体清单从 8 变为 6，使合法缓存键改变并新增一次 SAM 调用。
这不证明缓存存储损坏，也不证明完整复跑可以命中缓存。

独立真实 CV worker 的 SIGTERM/重启恢复测试已通过：租约过期后第二次所有权接管、
单次发布及精确证据重载均得到验证。**恢复测试不是缓存命中测试。**

### 5.3 有限语义复验：已结束

使用原冷跑输入，只复验一个场景阶段和一个遮挡阶段，每阶段初次调用加一次修复，
合计四次真实调用，无新 SAM 分析。监督过程耗时 236.559 秒；报告 token 用量为
613,199 输入、7,829 输出。这不是完整视频端到端耗时或金额账单。

- `full_0001` 场景：首次失败；修复通过，6 个对象、8 个语义事件，0 条位置、0 条关系。
- `full_0002` 遮挡：首次 `OCCLUSION_EVENTS_EMPTY`；修复仍为
  `OCCLUSION_EVIDENCE_PROHIBITED_CONTENT`，没有被接受的正例。
- 当时结论：不启动新五视频实验；保存失败并转向离线诊断。

## 6. 最近诊断、修复和验证

离线重放定位到三个问题：

1. 遮挡最后一次拒绝由证据文本中的一个普通斜杠触发。仅在内存替换该斜杠可以
   通过原校验，但不证明视觉语义正确。历史输出未修改。
2. 提示词只说“只有遮挡可以有事件”，未明确“遮挡必须有事件”；失败候选本身
   有合法时间边界，不是无时间可填。
3. 场景初次有 14 条空间记录，其中 13 条来源片段列表不符合契约，13 条含非观测
   时间边界；11 处用了视频时长而非最后观测帧时间。排序修复不足以解决全部问题。
   修复响应自行返回空列表，并非后处理删除。未发现引用未声明对象；有一条轨迹
   与所引用对象及区间不匹配。

`95807ee` 的修复保留原有验收条件，做以下对齐：

- 遮挡必须有至少一个可支持的正时长事件；否则使用 unknown 和空事件，不编造事实。
- 两个提示词明确证据字符串禁用斜杠等现有禁止内容；保留路径和掩码防护，
  不用标点白名单或自动替换来掩盖模型输出。
- 保留 `SCENE_SPATIAL_INVALID`，增加具体封闭类别，并聚合独立的时间、排序、
  对象、片段、轨迹、关键帧、来源元数据与文本错误。
- 明确复制 observed_clock 的精确时间，来源片段须包括所有时间相交片段，
  不是只挑对象相关片段；修复不能仅为消除报错就清空有支持的事实。
- 仍允许真正无支持时的空间弃权；不强制非空，不自动排序、吸附时间或补来源。
- 异常原文、任意代码、私有路径和拒绝内容不能进入公开修复反馈。

红绿验证先观察到 14 个预期失败，再实现具体错误反馈。最新产品检查点的完整
测试为 1,740 通过、覆盖率 85.87%；已开展的独立代码审查和针对性复审无剩余问题。
这不是承诺审查覆盖每一行，也不能替代后续 PR 审阅和真实验收。

四份旧响应在新校验器下的接受/拒绝结论未变；新代码只是提供更具体的失败原因。
最新提示词的真实模型行为尚未验证。见[详细修复报告](2026-09-06-semantic-repair-feedback.md)。
