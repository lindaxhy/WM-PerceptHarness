## 已修复的证据丢失

旧预算缩减器先清空关系、关键帧，再缩减冗余观测。即使修复这个顺序，摘要仍可能占满提示词预算，使真正的遮挡候选列表被再次裁剪到零。

修复现在共同预算摘要与候选，优先保留可见性转变附近的关系、关系双方在同一帧的观测，以及相关关键帧。线上流程和 LAS 评测重建入口传入同一组阈值。时间戳、候选身份、掩码来源和不完整标记继续由原合同校验；检测缺失不直接变成遮挡标签。

在初次修复检查点 `a1da788`，对五段历史原始缓存进行哈希校验后，使用默认 200,000 字符预算离线重建：

| --- | ---: | ---: | ---: | ---: |

## ARK 图像分辨率

`d78b491` 修复 ARK 适配器忽略 `media_resolution` 的问题。显式 low、medium、high 分别使用最大 65,536、131,072、262,144 像素，最小 4,096；未指定时保留服务默认行为。帧数、JPEG 内容和时间戳不变。字段依据为火山引擎 [官方 SDK 图像像素限制类型](https://raw.githubusercontent.com/volcengine/volcengine-python-sdk/master/volcenginesdkarkruntime/types/responses/response_input_image_pixel_limit_param.py)。

同一段视频的 22 帧短提示探测中，显式 medium 使用 1,859 输入 token、4.335 秒；不限制像素的对照使用 28,919 输入 token、10.111 秒。两次均调用固定的 `doubao-seed-2-1-pro-260628`。这仅证明参数被接受及这两次请求的成本差异，不能外推完整流程速度或语义精度。相关 104 项测试和独立审查通过。

`reasoning_effort`、`clip_context` 在当前 ARK 实现中仍是记录的请求提示；实际 thinking 为 disabled。本轮不能把这些提示记成已生效的模型行为。新像素设置是不同于历史运行的实验条件。

## 可重放语义与场景来源选项

`1efaad1` 增加持久语义结果缓存。缓存身份绑定实际视频哈希、提示词、模型、采样及验证合同，只有通过现有输出校验且仍持有任务租约的工作进程才能发布。重复任务可复用实体识别、分段和语义结果，避免随机实体清单使 CV 缓存失效。离线完整流程与修复重放测试通过；真实五视频重复门槛仍待验。

`b8d01c2`、`48e4155` 在推理前提供有限的场景来源选项，时间、轨迹、分段索引、关键帧均来自保留证据。模型仍须独立判断语义；输出不做事后修补。覆盖修复通过 48/64 物体及“早期窗口太长、后期窗口可容纳”的回归测试，独立复审通过。完整测试 1,821 项通过，尚未做这一版本的完整覆盖率检查。

同一历史输入上的来源选项诊断运行两次：场景调用在 79.041 秒后以 `MODEL_GENERATION_FAILED` 结束，未得到可校验输出，token 用量未知；遮挡调用 44.192 秒，使用 111,541 输入、1,925 输出 token，首次结构有效，仍有 11 个正例和 4 个出画判断。正例仍包含桌面碎片解释与近重复球事件，因此不能宣称精度改善。至此累计 11 次 ARK 调用，零次 SAM 调用；该诊断另存为 `semantic-provenance-options.json`。仅场景的受控错误诊断另调用一次，确认同一提示触发 `incomplete`、原因为 `length`，输出正好 4,096 token，输入 113,344 token。该结果被拒绝；它说明现有场景输出预算不足，但不能反推前一次未知错误的原因。累计调用更新为 12 次，SAM 仍为零次。

## 后续诊断与修复

`9b95f7c`、`f34bcd1` 将 SAM 掩码统计中的 Python 逐像素循环替换为字节计数和压缩迭代。审查发现并修复了字节子类覆盖计数方法的校验绕过。面积、质心使用精确相等断言，归档字节对照不变。完整测试 1,827 项通过，独立复审通过。同一远端环境、同一批 12 个历史掩码上，实际生产统计函数三次测量中位数从 1.581 秒降至 0.599 秒，结果哈希完全一致。这是统计函数性能，尚不是 SAM 推理或任务端到端速度。

一次独立 Pass A 诊断耗时 12.338 秒，使用 3,834 输入、416 输出 token；验证得到五个实体，分别包括浅木板和后段灰边白板。它验证了本次实体清单提取，未验证后续 SAM 物理身份关联。

`2fbfe2a` 将 ARK 场景输出上限调整为 8,192，其他 ARK 阶段和 Qwen 上限不变，并提示选择不重复的代表性来源选项。请求与缓存身份使用相同实际上限，268 项相关测试及独立审查通过。真实场景复验两次均完整生成，却仍未通过校验：首次使用 113,445 输入、3,182 输出 token，74.420 秒；修复使用 113,460 输入、2,860 输出 token，66.393 秒。错误包括不允许的关系枚举，以及顺序、非观测时间和分段来源不匹配。不能把消除截断称为场景能力通过。至此上述语义诊断累计 15 次 ARK 调用，零次 SAM；额外接口格式探测单独记录。

身份审计校验了两个历史掩码归档及选定关键帧。几个换号前后掩码 IoU 为 98.6%–99.2%，不同实体标签的重复区域掩码 IoU 超过 99.3%。这支持轨迹延续和标签歧义假设，不能证明七次独立物理遮挡。当前 `edge_departure` 实际记录末次边框靠近图像边界，不等于观测到向外运动。审计为 AI 辅助诊断，不是人工验收；见 [身份诊断证据](../../evaluation/results/las_capability_2026-09-06/physical-identity-diagnostic.json)。

`bb0da6b` 已实现候选 v2：给出观测来源约束的进入、持续、离开遮挡时间选项，以及有限的轨迹延续和标签冲突线索。线索仅来自保留几何，不宣称在线计算了掩码 IoU，不自动合并轨迹或删除语义正例。场景输出仍需进一步解决来源字段抄写和枚举错误，五视频新冷跑尚未启动。

## 候选身份线索预算与真实产物复查

`af73705` 修复实际身份线索被预算全部清空的问题：先为有限的真实线索预留空间；预算更紧时按候选公平保留完整线索行，并重新验证每行来源。完整测试 1,903 项通过，独立复审通过。

五段历史产物复查中，full_0001、full_0002、full_0004、full_0021 分别保留 64、46、64、41 行身份线索；full_0024 没有候选。所有联合记录都在 200,000 字符以内。之前四段视频的线索全部丢失的结果已单独保留。

调整摘要密度后，候选数变为 23、14、25、15、0。逐项比较轨迹、锚点帧和事件类型时间区间，确认没有改变检测缺失期间的进入、持续、恢复候选。全部 30 条增加或删除的区间均来自不确定观测窗口；其中两段视频各少一个此类候选。这是预算取舍，不能单独证明语义质量改善。

## 候选 v2 检查点的真实遮挡诊断

固定 `af73705`、输入包和 wheel 哈希的 full_0002 遮挡诊断只调用一次模型，耗时 49.512 秒，使用 112,097 输入、1,542 输出 token。14 个判断首次通过生产校验：3 个遮挡、3 个出画、8 个不确定。此前报为遮挡的 7 个桌面碎片候选全部变为不确定；3 个正例对应黄球的两次遮挡，其中第一次仍有重复判断。

用原有冻结评测器计算这一单阶段结果，在时间 IoU 0.3 和 0.5 下，事件 F1 均为 0.4444，区间 F1 均为 0.8。六个参考阶段事件中匹配两个，没有输出进入或离开遮挡的事件，并保留一个未匹配的重复区间。见 [单阶段评分](../../evaluation/results/las_capability_2026-09-06/candidate-v2-stage-scores.json)。

重复候选的来源已定位：黄球在帧 43、44、79 的已保存观测序号相邻，但帧 44 到 79 之间跨过已认证的缺失帧 45–78。现有不确定性规则忽略了这一连续性中断。后续 `4c1fa7c` 修复在已知缺失处中断不确定窗口构造，保留独立可见区间内的部分遮挡证据、原始观测和全部已有遮挡阶段，不从单侧证据编造更短事件。见 [重复窗口诊断](../../evaluation/results/las_capability_2026-09-06/duplicate-window-diagnostic.json)。

这只是单视频诊断，不能代替五视频门槛。评分按事件类型与时间匹配，不认证物理身份；历史 `wooden_board` 实体把两块不同的板合在一起，最终流程仍需用新的 Pass A 清单验证区分。模型自己描述的依据也不等于已认证的视觉事实。

另有两次极小结构化格式探测：嵌套 SDK 格式返回 HTTP 400；扁平 `text.format` 格式被同一模型接受，输出符合给定枚举。它只验证了极小模式，完整场景模式仍需验证。`8c9cd07` 已实现场景选择接口：模型输出证据编号，程序按认证来源填入精确时间和来源字段，再通过原有公开结构校验。缓存保存已验证的选择结构，公开结果按真实成功尝试生成来源历史；原始无效响应不会被改写成成功记录。完整测试 1,944 项通过，独立审查通过。真实历史输入生成 64 个来源选项和 7,698 字节的服务端约束模式；这只是本地编译检查，完整模式的远端支持仍待实测。

截至这一检查点，共 18 次诊断 API 请求，其中一次格式探测被 HTTP 400 拒绝；零次 SAM 调用。当前真实诊断进程均已结束，五视频冷跑尚未启动。

## 连续性修复与场景选择实测

`4c1fa7c`、`8eb0eb6` 在已保留的缺失帧处切断不确定观测窗口，保留独立部分遮挡证据。提示词明确：未跨越已知缺失不代表不完整观测已证明连续可见。五份历史产物的全部已有生命周期事件区间保持不变，四份含候选样本仍保留 50、35、64、39 行身份线索，联合记录均低于 200,000 字符。完整测试 1,949 项通过，覆盖率 86.75%；末次仅提示词修复另有 176 项相关测试通过。

固定 `8eb0eb6`、wheel `2043dbf22ba1e0374a8c3d2709241e8591d18fc5c1260c61375cbb2056c56875`、输入包 `3b2290c11a329d36e8f4ef33d811cd500ab45a39d670bc3921c980a7cfabd9b8` 的实测共三次模型调用、零次 SAM。场景首次出现额外字段和关系枚举错误，修复后通过，保留 9 条位置、5 条空间关系和 8 个语义事件。完整 7,698 字节约束模式被服务接受，但首次输出仍违反模式，因此不能宣称服务可靠地强制全部约束；本地校验继续作为最终约束。

至此有限诊断共 21 次 API 请求，零次 SAM。独立全分支审查另运行 761 项 Python 测试、20 项查看器测试及完整差异空白检查，没有发现新的严重或重要问题；两个既有依赖警告保留。代码审查不替代真实验收。

## 新五视频实验的首个实际故障

同一 `8eb0eb6` wheel 的新纯豆包对照启动后，full_0001 在约 142 秒完成推理，使用 6 次模型调用。Pass B 修复后有效，场景两次均有枚举错误，最终按合同标为不可用。独立公开结果校验又发现 `semantic_cache_key` 被通用敏感字段脱敏替换为 `***`；数据库中保存的是有效 SHA-256。这是新增缓存指标与公开响应之间的接口缺口。

实验驱动在首个样本验证失败后停止，没有提交余下四个视频。五个自有服务进程组已按身份安全停止，原数据库、任务句柄和失败响应均保留。后续仅在整份结果有效后恢复这个已验证、非敏感的指标字段，并添加真实 Poll 路径回归；通用凭证脱敏规则保持不变。场景枚举错误单独诊断，不把两类故障混为模型失败。

`1cc5d65` 已修复缓存哈希的公开响应恢复，130 项边界测试和独立复审通过。用真实已保存的 full_0001 结果重放公开投影，验证通过、与存储结果一致且未修改输入。第一轮实际耗时 142.208 秒，6 次调用共 30,600 输入、8,910 输出 token，失败证据见 [首个对照样本](../../evaluation/results/las_capability_2026-09-06/cohort-v1-control-failure.json)。
